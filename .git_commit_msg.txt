M3 closure: ODE basics + backward substitution + docs overhaul (arch/manual/api)

ODE foundation (cas/ode.py + :dsolve):
- four classified problem kinds, each named and logged:
  direct (y'=f(x)), separable (x/y factor splitting with numeric-sign
  preservation, power-family explicit inversion, implicit fallback),
  linear1 (integrating factor exp(int p), solution as (G+C1)*exp(-P)),
  constcoef2 (characteristic equation: distinct/repeated/complex roots
  with trig real form e^{ax}(C1 cos bx + C2 sin bx))
- solution verification by differential back-substitution through
  equivalent() -> VERIFIED/PROBABLE/UNVERIFIED (honest tri-state)
- reconstruction guards: linear remainder and homogeneous remainder must
  rebuild exactly (prevents y^2-class nonlinear terms from being swallowed
  by zero coefficients)
- custom _coef: opaque coefficients tolerated (exp(x) etc), wider than
  ops.coefficient which is Poly-based

Backward substitution (cas/bsub.py + :bsub):
- bounds solved via principal inverses (spec.inv; sin->arcsin etc,
  special-point folding gives exact pi-rational bounds)
- restricted auto-rewrite over transformed integrand (Pythagorean
  moved forms 1-sin^2 -> cos^2 added to trig.rules as auto rules)
- sqrt(cos^2)/|cos| shell removal via declarative trig nonnegativity
  windows (pi-rational bound comparison only; undecidable stays honest)
- classic cases verified: int_0^1 sqrt(1-x^2) = pi/4 (x=sin t),
  int_0^1 1/(1+x^2) = pi/4 (x=tan t)
