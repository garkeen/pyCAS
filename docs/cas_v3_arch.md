# pyCAS v3 架构

本文是唯一设计权威。读者可以是任何人或任何模型：所有概念在首次出现处给出解释，无需项目外部上下文。

定位：通用、纯符号、自动与交互双通道的计算机代数系统。

文档自底向上组织：先立语言契约与地基，再立系数域格，再立构造层与公共算法机器，再立功能，最后是验收标准。每一层为上一层提供构件。

---

## 一、总纲

### 1.1 三条系统性质

- 通用：覆盖方程求解、不等式、微分、积分、化简、级数、求和、线性代数
- 纯符号：全部计算建立在精确算术之上。整数与有理数用任意精度表示；代数数用 Thom 编码表示与比较——Thom 编码用极小多项式各阶导数在某根处的符号组合唯一标识这个根，全程只用精确算术。系统内不存在任何数值近似
- 双通道，且两通道的义务不对称：
  - 手动通道：每一步必须过程可解释、可验证，携带严格守卫条件。步骤的推导类型显式标注它是等价还是蕴含
  - 自动通道：算法自由选择计算方式，不要求过程可解释，只要求结果过独立验证器；验证不了的诚实回未决，绝不静默通过

### 1.2 语言契约（第一约束，先于一切子系统）

- 判定结果是代数数据类型而非字符串：`Yes(证据)`、`No`、`Unknown(理由)`。匹配必须穷尽，漏分支是错误
- 失败是返回值的一部分，禁止用异常吞掉错误；空缺用 None/Option 表达
- 未决理由只有四种，后果完全不同：
  - FRAGMENT：片段没覆盖，表达式含没见过的结构，扩库或扩域即可解决
  - GUARDED：被未确认条件挡住，条件清偿后答案自动翻转
  - UNDECIDABLE：可证不可判定。这一格的每一条都必须引用数学定理（希尔伯特第十问题、Richardson 定理等），不是能力占位符
  - BUDGET：可判定但资源超限

### 1.3 逻辑层与语义来源

逻辑层是**命题复合 + 域特定可判定原子**，不是一阶逻辑，不是定理证明器。系统不做运行时量词推理。全称事实是图书馆引理，按模式匹配实例化。复合层只需三值命题运算 and3/or3/not3，传播首个未决理由。

CAS 依赖的三种语义各自的来源：

- 代数语义（等式、规则）：域判等（片段内完全判定）+ 图书馆规则（无条件恒等式才入册）
- 序语义：decide 判定管线——假设帧 + 区间通道 + 图书馆常数界引理。序只在有序域上有意义，是域的能力字段，不是全局预设
- 逻辑语义：命题复合 + 守卫清偿 + 排中律分支。分支帧语义：帧内结论作为条件命题成立，矛盾假设不做一致性检查

### 1.4 验证独立性

- 验证器与求解器必须是两套独立实现，自己验证自己等于没有验证
- 手动步骤与自动结果过同一套验证器。验证器按推导类型分派：Solve 只做回代判官（代入 + 域标准形判零，不重跑求解公式）；微分结果由域层导数（另一实现）交叉复核；规则重写复核图书馆规则产物；分支切割验证排中律覆盖
- 启发式搜索可以探索任何问题：找到候选就送验证，通过即成立。未找到与不存在是两个结论，后者只能出自可判定片段的判定器并携带证据

### 1.5 阶段门控

Risch 积分（含参数与超越数情形，参照 FriCAS）是最终目标之一，但**地基完工前不启动**。地基 = 第四节公共算法机器全部就位（尤其线性代数与因式分解）+ 第三节系数域格至少完成 ℚ(i) 与单代数扩张。这条门控优先于任何功能排期。

## 二、地基

地基回答三个问题：表达式怎么表示，数字怎么算，系统怎么运转。

### 2.1 表达式的表示：驻留项层

- 表达式是不可变的树。内容相同的子树全系统只存一份（hash-consing），两个表达式完全相同当且仅当指针相同
- 交换结合头（Plus/Times/And/Or）保持两种不变量：嵌套同类节点拉平成一层；子节点按内容确定性排序。同值表达式的存储形态一致，交换结合相关的模式匹配无需搜索排列
- 布尔头额外做句法折叠：真值常元吸收（And 中 False 零元、Or 中 True 零元）、指针去重、a∧¬a 坍缩。这些是句法对，不涉及谓词语义
- 树上每个位置有稳定路径编号，手工编辑与步骤记录通过路径定位任意子表达式
- 积分、求和这类带约束变量的操作用绑定变量结构（de Bruijn 索引）表示，约束变量与外部同名符号互不干扰
- 本层只负责表示，保持纯句法。数值折叠属 ℚ 算术层，数学标准形属域层与图书馆

### 2.2 数字：任意精度算术

- 整数任意多位，加减乘除永远精确；有理数表示为自动约分的整数对
- ℚ 算术折叠只做普适恒等（数字子树精确折叠、中性元吸收、b^1=b），不做依赖域语义的归约（如 0^0、x^0 留驻给域层）
- 精确求值器对项在给定符号赋值下求精确有理值，越出环层（超越函数、未赋值符号）抛错拒答——这是回代判官的原子

### 2.3 系统骨架：工作流

一次完整工作流称为一个 calculation：初始环境加上不可变的步骤 DAG，外加一个当前位置指针。步骤不是等式链条——步骤间的逻辑关系由推导类型决定。

每个步骤的字段：序号、内容、推导类型、守卫元组、状态（open/dead）、操作对象路径、读写清单（本步读取与清偿的条件）、域归属（内容经投影命中哪个域）。

推导类型是封闭 ADT 层次，每种自带验证规则，分派到域判定器 + 命题复合：

- Claim：断言入账。守卫自动提取，逻辑地位为假设
- BothSides：等式两边同施加运算。可逆运算（add/sub/乘非零/除非零）为等价；不可逆为蕴含且信息丢失
- Rewrite：域标准形重写或图书馆规则应用，等价
- Solve：输入等式输出解。求解器交证书，验证器只做回代判官
- Split：条件分支切割，析取。排中律保证两支覆盖全空间；切割条件在该分支的守卫中清偿
- Subst：代换，纯句法，蕴含
- Diff：对前驱表达式求导。等式不是合法输入——两边求导不保真（点解方程 x=3 会"推出" 1=0），验证器一律否证；隐函数求导是带依赖声明的独立命令（未建）。验证由域层导数独立完成
- Integrate：对前驱被积式求原函数（不定）或积分值（定，bounds=(a,b)）。逻辑地位：不定为"原函数等式"，定为"积分值等式"。验证器独立于积分器——用微分层复核 d/dx antideriv == 被积式，定积分再核 值 == antideriv(b) − antideriv(a)
- Merge（待建）：多步骤汇合，合取。循环方程求解等需要多前驱

守卫条件系统：步骤创建时自动从内容提取定义域约束（负整幂底 ≠ 0、偶分母有理幂底 ≥ 0、log 底 > 0 等，约束本体注册在图书馆）。推导类型传播前驱守卫并叠加自身要求；守卫按指针去重；守卫被否决的步骤标 dead，并沿依赖边向下游级联。

上下文版本化（待建完成）：第 k 步的上下文 = 前 k 步依次作用于初始环境，含已知事实集、焦点表达式、假设帧、未确认条件集合。相邻版本结构共享，上下文条目反向索引建立步骤，形成读写双向索引。撤销与重做是切换位置指针；分支是从某步拉出新头；条件被推翻时沿读写清单级联 dead。答案完成时，未清偿条件逐条附在答案尾部——只是展示形态，本体始终在上下文中。

假设帧语义：帧内结论作为条件命题成立，假设帧不做一致性检查（矛盾假设下的结论依然条件成立）。全局事实冲突只做最便宜的多项式级检测，检出则打争议标记，判定系统对争议条目返回未决。

### 2.4 定义的家：图书馆

一切定义都住在图书馆里：常数、函数、规则、定义域条件、导数模板。制度：

- 条目内容寻址、不可变、有版本；先定义后使用在解析期整体强制
- 常数的正性、实性、粗界是声明数据，运行时查询，不写死在判定管线里
- 函数的定义域条件、值域界是声明数据，判定管线与守卫提取统一查表
- 函数的导数模板是声明数据（带绑定占位符），微分引擎实例化后乘链式因子；缺模板的函数诚实拒答并附说明
- 规则只能是无条件恒等式才入册为自动规则；带守卫的规则走显式应用通道，守卫经判定管线裁决
- 自定义函数入口（待建）：运行期注册函数声明；导数两个来源——用户交模板，或函数体是项时按体自动微分（纯代换，复用结构微分）

## 三、域系统：两条正交的轴

域不是一条链，是两条轴的乘积。**纵轴是系数域格**（常域，回答"系数是什么"），**横轴是构造**（变量侧，回答"在系数上建什么结构"）。算法按投影命中的域对象与域能力分派，不做叶嗅探。

### 3.1 纵轴：系数域格

从 ℤ 出发。下面按依赖顺序列出各格，顺序由构造依赖决定，不是难度排序：

**ℕ 有序半环**。离散、无减法封闭。只作为守卫语义与声明片段存在（非负性判断），不作为运算宿主。

**ℤ 欧几里得整环**。有序、带余除法、gcd 与扩展 gcd，但不是域——不能随便除，求解语义是整除而非除法。它入格有两个不可推迟的理由：
- 因式分解的必经之路：ℚ 上的 Zassenhaus 分解必须提升到 ℤ[x] 做（content、本原部分、高斯引理）
- 可判定丢番图碎片的宿主：线性丢番图方程（扩展欧几里得，有解 ⟺ gcd 整除）、单变量整系数多项式的整数根（有理根定理给出完备有限候选）。一般多元丢番图按希尔伯特第十问题归入 UNDECIDABLE 拒答——这是定理，不是 TODO

**ℚ 基域**。一切域构造的出发点。ℤ → ℚ 是分式化（局部化），不是域论意义的扩张。

**参数域 ℚ(t₁,…,tₙ)**。参数是相互超越独立的变元，但它**不是横轴上的一层构造，而是系数域的一部分**：处理"关于 x、带参数 a"的问题，系数域是 ℚ(a)，其上是 ℚ(a)[x] 与 ℚ(a)(x)。同一个式子，谁是系数谁是变量，决定能跑什么算法。参数的三条语义约定：
- 导数为零：在微分域语境下，"参数"就是导子核中的元素
- 代数关系未知：a²−4 是否平方、a 是否为零，默认不知；由此产生的答案必然携带条件（proviso）或走分支切割，这是算法内生需求而非附加品
- 语义由规则与假设给定：上下文假设帧是唯一给参数附加事实的通道。"任意实数"在计算意义上就是参数——计算机无法表示真任意实数，参数的序事实来自假设帧
参数格可与任何其它格复合：ℚ(α)(a) 表示带参数的代数扩张。

**ℚ(i) 高斯域**。代数扩张 ℚ[T]/(T²+1)。范数折回 ℚ 是它与上层算法的接口。

**ℚ(α) 代数扩张**。K[T]/(m)，m 是 α 的不可约首一极小多项式；元素是次数小于 deg m 的余式，乘法出口对 m 取余。建域前用 Capelli 型判定确认不可约，可约退化情形（如 √(x+1)² 类）诚实拒绝。实代数数的序与比较用 Thom 编码，全程精确算术。多扩张经本原元定理压缩为单扩张。

**ℚ̄ 代数闭包（计算意义的"复数"）**。真正的 ℂ 不是可计算域——它含 π、e 等超越数，无递归表示。系统所说的"复数"指 ℚ(i) 或复代数数；纵轴的计算顶端是 ℚ̄ = 全体有限代数扩张的定向并。

格的形状是 DAG 不是直线：ℚ(i) 与 ℚ(α) 是 ℚ 上的并列扩张，ℚ̄ 是它们的共同上界。混合运算找公共上域（见 3.3）。

### 3.2 域协议：能力字段

每个域对象自带代数事实，上层算法按能力分派，不按类型特判：

- 代数类别：半环 / 整环 / 域
- 是否有序；是否欧几里得（带余除法可用）
- 判等：返回真 / 假 / 非成员。片段内完全判定，片段外不答——不存在"域内未决"
- 标准形：成员测试 + 归一化
- 导数：系数导子，ℚ 与参数上恒为零，代数扩张上由极小多项式唯一确定（m(α)=0 两边求导：D(α) = −D(m)(α)/m'(α)）
- 分解能力标记：因式分解、gcd、线性方程可解性逐格声明

### 3.3 横轴：构造层与投影

在系数域 K 上逐层构造：

```
K[x₁..xₙ]  →  K(x₁..xₙ)  →  K(x)(θ) 代数塔  →  K(x)(τ₁,…,τₙ) 超越塔
```

投影是输入项落到构造的唯一通道：按成员测试阶梯 ℚ → K[x] → K(x) →（塔，待建），命中即返回域对象与域内元素表示，全部落空返回空——调用方据此拒答或升级。变元序取自由符号字典序，投影结果确定。**域由投影赋予，不做叶嗅探**。将来塔结构加入后阶梯在塔上继续生长，协议不变。

跨域运算的唯一通道是找公共宿主：两个运算对象投影后升到最小公共域运算一次；找不到公共宿主诚实返回未决，不猜。

### 3.4 导子随塔生长

导子 D 属于域协议，不是预先固定的全局符号。常数域上恒为零，向扩张生长时：

- 代数扩张：D 被极小多项式唯一确定（3.2 已述）
- 超越扩张：D 由生成元的定义方程指定。指数型生成元满足 D(τ) = w·τ，对数型（primitive）满足 D(τ) = w

每建一层登记该层生成元的 D 规则。

**塔不变量**：每一层的导子核必须恰好等于声明的常数域。反例：把 e^(ix) 和 e^(−ix) 当作两个独立生成元加入，两者乘积减一导数为零、形式非零，一个不属于任何声明常数域的假常数混进来，残数运算随之全部失真。维持手段：互为倒数的生成元共用同一层，负指数登记为已有生成元的负幂次。

**注册纪律**：代数域与根式参数的注册限定在单次计算的作用域内。v2 的全局可变注册表泄漏出过假 VERIFIED，这条纪律是它的墓志铭。落地机制（`cas/domains/base.py`）：单次计算域声明 `scoped=True`，`register()` 对其拒注册，必须经 `domain_scope()` 上下文管理器注册——退出（含异常）即注销，与常驻基域或外层作用域重名即拒绝。

## 四、基础功能：公共算法机器

域就位后，以下机器服务全部上层，独立公共模块，禁止被积分或化简等子系统私有复制。

### 4.1 多项式代数（对任意系数域实例化）

- 四则与伪除；单变量欧几里得 GCD（已建）、多变量 GCD（待建，接入有理函数约简）
- 无平方分解
- 结式与子结式链：消元的核心工具，残数法、CAD 投影、Thom 编码全靠它
- 因式分解按系数域定制：ℚ 走 Zassenhaus（提升 ℤ）；ℚ(i) 取范数折回 ℚ 再提升；代数扩张走 Trager 范数法；含参域走多元 Hensel 提升——全系统最贵的一格

### 4.2 有理函数代数

- 互素分子分母表示，交叉相乘判等，单变量 GCD 约简（已建）
- 部分分式分解
- Hermite 约化：积分问题递归削减为更低幂次
- Rothstein-Trager 残数法：对数项系数作为未知常数，用结式解出

有理函数的不定积分在这两层机器上完整闭环，不需要更高结构。

### 4.3 线性代数

域上行消元、Bareiss 行列式、零空间求解。**Risch 的线性相关性判定、待定系数、参数化对数导数判定全靠它——是地基门控的硬条目。**

### 4.4 域导数机器（已建）

系数导子（Ring 协议）→ 多项式导数 → 有理函数导数（商规则）→ 项层结构微分（图书馆模板 + 链式法则）。两套实现互为验证器。

## 五、表达式的结构世界

基础机器之上，表达式按结构分类。每类声明表示、核心算法、判等方式：

| 结构 | 表示 | 核心算法 | 判等 |
|---|---|---|---|
| 常数（纵轴任一格） | 各域自身 | 3.1 各格 | 域判等 |
| 多项式环 K[x] | 稀疏单项式表 | 4.1 全部 | 标准形（完全判定） |
| 有理函数域 K(x) | 互素分子分母 | 4.2 全部 | 交叉相乘（完全判定） |
| 代数塔 K(x)(θ)，θ^q = f(x) | 次数小于 q 的余式 | Capelli 守卫、Trager 范数分解、迹 Hermite、残数积分；根式与分数幂去壳后全归此层 | 标准形，前提是拒绝退化情形 |
| 超越塔 K(x)(τ₁,…,τₙ) | 塔上分式 | Risch 全套：Hermite 推广、RT 残数、RDE 求解器、参数化对数导数判定 | 塔覆盖片段内有标准型 |
| 级数与渐近 | 良序广义级数（transseries） | transseries 算术、首项比较定极限 | 片段内有标准型 |

五个边界裁定：

- 三角函数按图书馆定义展开为复指数，落进超越塔。sin²+cos²=1 由商环算术自动成立，全程无恒等式规则参与
- **分段函数**：Piecewise 头 + 分支条件（值/条件成对）。分支体不要求同一宿主结构——每个分支独立投影，多项式段在有结构的域里跑、超越段落回驻留项，容器域无关。条件可以是任意命题：判定管线判得动就给真值，判不动就以 GUARDED 未决传播，不假装分支不存在。唯一被约束处是重叠区：两分支交叠处值是否一致归约为恒等判定，同域内完全判定、跨片段按边界表诚实。覆盖完全性是使用者声明，系统不擅自补全；分支覆盖与切割推理共用工作流 Split 的条件语义
- **自定义函数**：图书馆运行期注册（2.4）。函数体是项时，微分、代换、展开按体计算；无体的抽象函数头留在交互通道，只享有关于它的声明事实
- 参数积分走主管线：参数在系数域里（3.1），整条管线在含参系数域上原样运行，通式附使用条件出门；参数取特殊值导致答案变形的情形由假设帧与分支切割处理
- 特殊函数头（Si、Erf、Bessel 等）：查图书馆定义。声明为独立超越生成元的进塔，未求值形式留在交互通道

输入项如何落到结构：投影阶梯（3.3）逐格成员测试；多种结构混合则找公共宿主，例如 e^x + √x 意味着同一座塔挂两层生成元。专用算法先行，失败再升级泛型：有理积分不惊动 Risch，多项式 GCD 不碰因式分解。

## 六、进阶功能与它们的算法

### 6.1 微分（已建）

导子的链式法则逐层穿透表达式：项层结构递归（线性、莱布尼茨、幂/指数/一般幂规则、图书馆模板实例化 × 链式因子），覆盖任意系数域 × 任意已声明函数域。域层导数是独立实现，交叉验证项层结果。塔建成后，微分自动获得塔层穿透——D 规则在 3.4 逐层登记。

### 6.2 不定积分（门控中）

按被积式所属结构分派：

- 有理函数：K(x) 内完整闭环。Hermite 约化 + RT 残数。例：∫dx/(x²+1)，残数 ±i/2 由结式解出
- 含根式：升代数塔。迹约化加残数。例：∫dx/√(x²+1) = ln(x+√(x²+1))
- 含 exp/log：升超越塔，运行完整 Risch。组件：Hermite 推广削重极点的有理部分；RT 残数给出对数项系数；Liouville 拆分限定答案形状；RDE（y'+fy=g）求解器负责核心，其度界理论决定搜索完备性；参数化对数导数判定处理待定整数系数
- 含参数：管线在含参系数域上运行。例：∫e^(ax)dx = e^(ax)/a 附 a≠0 条件
- 初等原函数不存在：同一套理论输出否定结论加证据链。正负两方向都有定理背书，这是 Risch 区别于启发式拼凑的本质

### 6.3 定积分

入口协议：积分区间与被积函数定义域守卫先做符号交，然后三分支——区间完全在定义域内则正常计算；交集可证为空则返回无定义（不给零：被积函数在那里不存在）；部分重叠则在有定义部分计算附条件，或按图书馆声明的复延拓分支切区间。悄悄缩小区间是被禁止的行为。

对称性定理独立于牛顿-莱布尼茨：奇函数对称区间积分为零（不需原函数存在）；周期函数有周期折叠。

### 6.4 方程与不等式

- 单变量代数方程：因式分解降次；二次以内根式闭式；三次以上 RootOf 表示（极小多项式 + 根序号），比较与运算走 Thom 编码
- ℤ 上：线性丢番图（扩展欧几里得）、单变量整数根（有理根定理）；一般情形按定理拒答（7.3）
- 多元方程组：Gröbner 基消元
- 不等式：Sturm 符号判定与 CAD（柱面代数分解）——实闭域上多项式不等式与量词消去的完备决策程序。可复用零件：结式与子结式链、Sturm 序列、ℚ(α) 精确赋值；需新写：McCallum 投影包装、Thom 编码、胞腔树簿记、量词记账、解公式组装、相邻根的代数中点样本
- 根与序的四个原子问题（存在/计数/比较/零等价）的可判定性地图与 L0-L5 分层见 7.4；分段操作中 Unknown 的三条出口协议见 7.5

### 6.5 极限与级数

transseries 承担：渐近展开、级数算术、首项比较输出极限值或符号判定。

### 6.6 求和与差分

差分演算与微分平行：Δ 之于求和等于 D 之于积分。Faulhaber 幂和、Gosper 算法判定超几何项封闭和、定界求和。

### 6.7 微分方程

常系数线性 ODE 走特征方程 + 线性代数；一阶初等 ODE 直接消费 RDE 求解器。PDE 只覆盖声明的可判定类别。

## 七、判定与验证

### 7.1 判定管线

规则触发前检查守卫；判零统一走所在域的标准形比较；无法确定时返回未决并携带 1.2 定义的四种理由之一。序判定：假设帧 → 区间通道（链式不等式的图搜索）→ 结构符号引理 → 图书馆常数界与函数值域界，全部输出判定契约类型。

### 7.2 验证系统

验证器按推导类型分派（1.4），全部独立于求解器实现。核心原子是回代判官：声称的解回代原式，精确求值必须为零，不需要外部真值。

### 7.3 拒答协议表

| 触发情形 | 边界名称 | 理由等级 |
|---|---|---|
| ℤ/ℕ 上一般多项式方程解的存在性 | 希尔伯特第十问题（Matiyasevich 1970） | UNDECIDABLE |
| 指数多项式求整数零点 | Skolem 问题，尚未解决 | FRAGMENT（开放） |
| ℚ 上多项式方程解的存在性 | 希尔伯特第十问题之 ℚ 版本，公开未决 | FRAGMENT（开放） |
| 超越常数组合判零且库里无引理 | Richardson 定理 | UNDECIDABLE |
| 超越方程的根之间比大小且无库内事实 | 无完备算法 | UNDECIDABLE |

发现新的已知边界就增补一行。这张表是数据，防止边界共识随换人蒸发。注意区分两类拒答：定理保证不可判定的用 UNDECIDABLE；连"是否可判定"都未解决的用 FRAGMENT 并标注开放——前者是数学结论，后者是诚实留白。

### 7.4 根与序：可判定性地图与分层实现

分段函数的一切操作——求导的分段点、定积分的区间切分、解方程的支域、条件合并——最终都归结为四个原子问题：根**存在吗**、**有几个**、**谁大谁小**、**两个对象相等吗**（零等价）。这四个问题的可判定性随数域扩张断崖式下跌，这张地图决定哪些层能建、哪些层只能拒绝：

| 原子问题 | 代数世界（ℚ/代数数系数与端点） | 超越世界 |
|---|---|---|
| 根存在性 / 计数 | **可判定**：单变量 Sturm 计数；多变量 CAD（代价对变量数双指数） | 含全轴 sin：**不可判定**；仅 exp：开放（Schanuel 猜想下可判定）；知识覆盖的局部情形（已知单调性/零点集）可判 |
| 根隔离与排序 | **可判定**：隔离区间 + 加细；Thom 编码做精确算术与比较 | 可分离根：**可靠半判定**（区间加细到分离即证不等）；判等**无完备算法** |
| 端点 / 常数判等 | **可判定**：极小多项式相同 + Thom 符号一致 | **不可判定**（Richardson 定理，7.3 第四行） |
| 实闭域量词消去 | **可判定**（Tarski；Collins CAD 1975） | ℝ_exp：Macintyre–Wilkie 1996 在 Schanuel 猜想下可判定，无条件未解决；ℝ+sin 不可判定 |

理论锚点（每条都是公开数学结论，不是能力占位符）：

- π 一阶可定义为"sin 的最小正零点"，而 sin(πx)=0 ⟺ x∈ℤ——(ℝ,+,·,sin) 解释出整数算术，理论不可判定。这是"超越根不止一个怎么排序"类问题无完备算法的根源：不存在的东西不能靠工程补出来
- Richardson 定理（1968）：由 ℚ、π、log 2、exp、sin、|·| 复合而成的常数判零不可判定。区间算术对"≠"是半判定程序——加细到区间分离即证明不等；分不开时不存在更强算法，只能 Unknown
- CAD 双指数于变量数：多变量代数情形可判定但昂贵，单变量 Sturm 是代价锚点——分层先建一维是成本依据，不是权宜

分层实现（顺序即依赖序；每层的合法性条件：输出过验证器或携带 Verdict，层内"分不开"如实升级为 Unknown）：

- **L0 代数核（已建）**：一维 CAD + Sturm 根隔离 + 胞腔符号判定，精确完备
- **L1 ℚ(α) 精确化**（路线图步骤 5）：代数端点的精确算术与比较（mod-m + Thom 编码），把"无理分界点拒答"清成可判定——这一格是 FRAGMENT，不是 UNDECIDABLE，纯增量
- **L2 区间算术比较层**：可计算函数（exp/log/sin/ atan…）的任意精度区间求值——分离即 Yes/No，重叠即 Unknown。这不是启发式：它是"≠/<"在 Richardson 墙下最强的可靠程序，输出天然是 1.2 的 Verdict。数值只以带误差界、可无限加细的隔离形式出现，裸浮点禁止进入符号通道
- **L3 图书馆序引理**：单调性、零点集（sin 零点恰为 kπ）、周期、凸性作为 FunctionDecl 数据入册——知识覆盖的局部超越比较由 FRAGMENT 降为可判。序引理与导数模板同一准入纪律：无条件可证者才入册
- **L4 超越根对象**：(方程， 隔离区间) 对象 + 加细协议。排序靠区间分离；等号仅在可证时成立（同定义方程且隔离区间重叠，或库内引理）。根簇、疑似重根、周期外的无穷多根一律拒绝
- **L5 包络归约（后置可选）**：Taylor/Remez 有理包络把超越不等式严格归约为代数不等式，再交实闭域判定（MetiTarski 路线）——可靠不完备，作 L2/L3 的增强而非替代

### 7.5 Unknown 的出口纪律

"任何环节出现 Unknown 就整体拒绝"是过粗的规则：它一并禁掉了条件化答案（端点序未决时，答案本身可以按参数条件分支给出——未决性被**提升为答案结构**，不是被消灭）与开放步骤（验证未决 ≠ 内容被否证）。正确的不变量是：

**Unknown 只能沿三条显式出口离开系统，绝不静默消解。**

1. **条件化传播**：未决比较提升为答案中的显式条件（条件分支容器承载），答案同时携带完备性声明——`complete`，或 `partial`（附逐条未决清单）。枚举型通道（契约是"全部解"）任一支未决时，要么整体拒答，要么显式降级为 partial 并列出未决项；已知解与未决项不允许无标注地混在一起
2. **开放步骤**：验证未决 → 步骤 open，永不 dead。No 必须携带证据（1.4），无证据不得声称否证
3. **带理由拒答**：按 1.2 四理由分派；定理级边界逐行对照 7.3 表

禁止的消解方式（一律视为作弊）：静默选支（把 Unknown 当真/假使用）、静默丢支（部分解冒充全解）、generic 答案（稠密开集上正确冒充全域正确——某些商用系统的默认取舍，本系统明确不采纳）、无误差界的数值定序混入符号通道。

用户消解通道：假设/split 是唯一合法的第三方消解——用户为具体实例注入比较事实或假设，帧内重判，GUARDED 守卫清偿后答案自动翻转。其边界：注入的事实只对该实例生效，系统不得据此把 7.3 表的 UNDECIDABLE 行改判为可判——定理针对一般情形，实例事实不推翻定理。

## 九、验收方法论

- 随机性质测试：生成器构造已知答案的表达式，用域判定器验证性质，全部自证、无外部真值。当前四十一条（P1-P41，逐项见 progress.md"压力台架"），以 pytest 收集层（`stress/test_stress.py`）统一驱动、CI 守门
- 差分生成器（积分阶段启用）：随机生成初等函数 F，要求 integrate(dF/dx) 且结果求导回到 F。覆盖率的唯一来源
- 回代判官：验证系统的原子，已建
- 验证独立性：每条推导类型的验证器必须与被验证算法实现不共享代码路径
- 钉子库：退化形态与修过的 bug 逐个固化成测试，持续积累
- 符号反证：系统给出否定结论时，用符号方法生成候选反例逐一排除，保证否定可靠
- 文档现实锁定：文档声称存在的模块，磁盘上必须有

这七件构成完整的裁判标准。
