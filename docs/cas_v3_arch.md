# pyCAS v3 架构

本文是唯一设计权威。读者可以是任何人或任何模型：所有概念在首次出现处给出解释，无需项目外部上下文。

定位：通用、纯符号、自动与交互双通道的计算机代数系统。

文档自底向上组织：先立地基，再立数域，再立基础功能，再立函数结构与进阶功能。每一层为上一层提供构件，最后一节的功能清单是整座建筑的验收出口。

---

## 一、总纲

三条系统性质：

- 通用：覆盖方程求解、不等式、微分、积分、化简、级数、求和、线性代数
- 纯符号：全部计算建立在精确算术之上。整数与有理数用任意精度表示；代数数用 Thom 编码表示与比较，Thom 编码用极小多项式各阶导数在某根处的符号组合唯一标识这个根，全程只用精确算术。系统内不存在任何数值近似
- 双通道：既有完整的自动判定算法，也有逐步手工操作通道。当前优先级是交互通道，自动求解作为战术层在交互通道内消费

当前阶段以交互式手动操作与最简解方程为目标。Risch 积分、CAD 量词消去等远期功能的基础算法路线图保留在第四至八节，不因当前优先级调整而删除。

逻辑层是**命题复合 + 域特定可判定原子**，不是一阶逻辑，不是定理证明器。系统不做运行时量词推理，不做归纳类型。全称事实是图书馆引理，按模式匹配实例化。复合层只需命题逻辑的三值运算：and3 / or3 / not3。

自动化算法与认证：

- 自动化算法自由选择计算方式，直接实现判定过程或走规则重写均可
- 无论哪种方式，结果一律过验证系统。验证器与求解器必须是两套独立实现，自己验证自己等于没有验证
- 自动化算法只在可判定片段内作答，片段之外的输入按拒答协议表处理
- 启发式搜索可以探索任何问题：找到候选就送验证，通过即成立。搜索未命中时返回未找到；未找到与不存在是两个不同的结论，后者只能出自可判定片段的判定器并携带证据链

语言契约是第一约束，先于一切子系统：

- 判定结果是代数数据类型而非字符串：Proved 携带证据、Refuted、Undecided 携带理由
- 匹配必须穷尽：漏掉分支是编译错误
- 失败是返回值的一部分，禁止用异常吞掉错误
- 空缺用 Option 类型表达

Undecided 的理由只有三种，后果完全不同：

- 片段没覆盖：表达式含有没见过的结构，扩库即可解决
- 被未确认条件挡住：条件清偿后答案自动翻转
- 根本不可判定：Richardson 定理保证初等函数组合的零等价一般无法判定，永远只能靠图书馆新增引理

## 二、地基

地基回答三个问题：表达式怎么表示，数字怎么算，系统怎么运转。

### 2.1 表达式的表示：驻留项层

- 表达式是不可变的树。内容相同的子树全系统只存一份，因此两个表达式完全相同当且仅当指针相同
- 加法与乘法的子节点保持两种不变量：嵌套同类节点拉平成一层；子节点按内容排序。这两条保证同值表达式的存储形态一致，使交换律结合律相关的模式匹配无需搜索排列
- 树上每个位置有稳定路径编号，手工编辑与步骤记录通过路径定位任意子表达式
- 积分、求和这类带约束变量的操作用绑定变量结构表示，约束变量与外部同名符号互不干扰
- 本层只负责表示，保持纯句法。数学意义上的标准形由第四节的函数结构提供

### 2.2 数字：任意精度算术

- 整数任意多位，加减乘除永远精确
- 有理数表示为自动约分的整数对
- 这是全系统唯一的数字来源，之后的所有系数域都由这一层构造

### 2.3 系统骨架：工作流

一次完整工作流称为一个 calculation：初始环境加上不可变的步骤 DAG，外加一个当前位置指针。步骤不是等式链条——步骤间的逻辑关系由推导类型决定。

每个步骤包含七个字段：

- sid 与 parent：序号；开分支时 parent 指向分叉的那一步。DAG 允许多前驱（如循环方程求解同时消费两个方程步骤）
- op：操作来源，手动命令或者自动求解器标识加算法名
- target：操作对象的路径
- 载荷：本次操作专属的数据本身。换元操作存储 g 与 t 的对应关系这个数据，规则应用存储绑定，求解存储解和证书
- before 与 after：操作前后两个表达式的引用
- 上下文读写清单：这一步读取了哪些已确认条件、建立了哪些新事实、清偿了哪些未确认条件。上下文里的每个条目也反向记录自己由哪个步骤建立，形成双向索引
- status：live 或 dead。依赖的条件后来被推翻时标记为 dead

推导类型是封闭 ADT 层次，决定步骤与前驱间的逻辑关系。每种类型自带验证规则，分派到域判定器 + 命题复合：

- Claim：断言入账。守卫自动提取，逻辑地位为假设
- BothSides：等式两边同施加运算。可逆运算（add/sub/mul by 非零/div by 非零）为等价；不可逆（mul by 0）为蕴含且信息丢失
- Rewrite：域标准形重写，等价
- Solve：输入等式输出解集。完备时为解集等价，验证靠回代判官
- Split：条件分支切割，析取。排中律保证覆盖全空间
- Merge：多步骤汇合，合取

守卫条件系统：步骤创建时自动调 dom_condition 提取定义域约束。负整幂底 ≠ 0、偶分母有理幂底 ≥ 0、log 底 > 0、sqrt 底 ≥ 0 等。BothSides 传播前驱守卫加运算元守卫；mul/div 额外要求运算元 ≠ 0，由 decide 在已积累守卫的上下文中检查。守卫不满足时步骤标记 dead 并沿 DAG 向下游传播。

上下文在第 k 步的取值等于把前 k 个步骤依次应用到初始环境上的结果：已知事实集、当前焦点表达式、打开的假设帧、未确认条件集合。每执行一步保存一个新的上下文版本，相邻版本共享未变化的部分。

- 撤销与重做就是切换位置指针
- 分支就是从第 k 步拉出新头。两个分支对同一个未确认条件给出不同裁决，各自的答案自然不同
- 某个条件后来被推翻时，沿读写清单找到依赖它的步骤标记 dead，继续向下游传播
- 未确认条件的本体始终保存在上下文中；答案完成时，把其中尚未清偿的逐条附在答案后面显示。答案尾部的这些条件只是展示形态
- 序列化保存步骤流。上下文随时可以从步骤流重新推算

假设帧的语义：帧内推出的结论作为条件命题成立，假设帧本身永远不做一致性检查，因为在矛盾的假设下推出的结论依然条件成立。全局事实之间的冲突只做最便宜的多项式级检测，检出就给两条事实打争议标记，判定系统对争议条目返回 Unknown。

### 2.4 定义的家：图书馆

一切定义都住在图书馆里：函数的定义、常量的定义、操作的语义、规则库。具体条目随各功能节展开，制度在此约定：

- 全部条目内容寻址、不可变、有版本
- calculation 用 use 引用锁定所依赖的库版本，库升级不影响旧计算的回放
- 先定义后使用在解析期整体强制：出现未解析引用，整个输入拒绝执行
- 函数定义域条件由图书馆声明注册，内核运行时查询。log 的底要求大于零、sqrt 的底要求非负等约束在图书馆登记，不写死在判定管线里

## 三、数域系统：系数住哪

从有理数域出发逐步构造。每次添加一类生成元，各次添加互相独立：

- 添加虚数单位 i，得到高斯有理数域。它是代数扩张 ℚ[T] 除以 T²+1 生成的商环，不设专门类
- 添加参数：参数是相互超越独立的变元，导子为零
- 添加代数数 α：得到代数扩张 K[T]/(m)，其中 m 是 α 满足的不可约首一多项式。元素是次数小于 m 次数的余式，乘法出口对 m 取余。建域前用 Capelli 判定确认 T 的多项式确实不可约，像 x 加一的平方根这种可约退化情形会被诚实拒绝，因为它存在更简单的表示

每个域声明自己的判等方式，三选一：

- CANONICAL：域内元素有唯一标准形，判等就是比较标准形
- FORMAL：只计算形式恒等式，零等价无法在此域内判定
- BRANCHED：相对某个分支约定有效，结果强制附带条件

混合域规则：代数部分 CANONICAL 叠加超越部分 FORMAL 时，整域按 FORMAL 处理。pushout 的结果域取两边中较弱的状态。

跨域运算的唯一通道是 pushout：找到同时包含两个运算对象的最小扩域，提升两边，运算一次。找不到公共扩域时返回 Unknown。

代数数之间的比较：Thom 编码按字典序比较，由子结式链完成符号判定，全程精确。

超越常数之间的序事实：一律为图书馆已证明的引理，比如 3 小于 π 小于 22/7 这类条目。运行期涉及超越常数的判断全部查表。代数数与超越常数比较同理。

导子 D 属于域协议。它在常数域上恒为零，向扩张生长时有两种定义方式：

- 代数扩张：D 被 m 唯一确定。m(α)=0 两边求导推出 D(α) = −D(m)(α)/m'(α)
- 超越扩张：D 由生成元的定义方程指定。指数型生成元满足 D(τ) = w·τ，primitive 型生成元满足 D(τ) = w

每建一层登记该层生成元的 D 规则。D 随着塔扩张逐步生长，它是结构数据，不是预先固定的全局符号。

塔不变量：每一层的导子核必须恰好等于声明的常数域。反例：把 e^(ix) 和 e^(−ix) 当作两个独立生成元加入，两者的乘积减一这个东西导数为零、形式上又非零，一个不属于任何声明常数域的假常数混了进来，残数运算随之全部失真。维持手段：互为倒数的生成元共用同一层，负指数登记为已有生成元的负幂次。

注册纪律：代数域与根式参数的注册限定在单次计算的作用域内。v2 的全局可变注册表泄漏出过假 VERIFIED，这条纪律是它的墓志铭。

## 四、基础功能：公共算法机器

数域就位后，以下算法机器服务全部上层。它们是独立的公共模块，禁止被积分或化简等子系统私有复制。

### 4.1 多项式代数，对任意系数域 K 实例化

- 四则与伪除
- 最大公因式，用多项式余式序列计算，扩域上用子结式链
- 无平方分解
- 结式：消去一个变元得到的行列式，是后续残数法与 CAD 投影的核心工具
- 因式分解按系数域定制：ℚ 上走 Zassenhaus 方法；高斯域上取范数折回 ℚ 分解再提升；代数扩张上走 Trager 范数法；含参域上是多元 Hensel 提升，这是整个系统最贵的一格

### 4.2 有理函数代数

- 表示为互素分子分母，分母首一
- 部分分式分解
- Hermite 约化：把积分问题递归削减为更低的幂次
- Rothstein-Trager 残数法：对数项的系数作为未知常数，用结式把它们解出来

有理函数的不定积分在这两层机器上完整闭环，不需要更高结构。

### 4.3 线性代数

- 域上行消元、Bareiss 行列式、零空间求解
- 上层的待定系数法与参数化判定把它当作高频工具

## 五、函数结构：表达式的五个世界

基础机器之上的表达式按结构分为五类。每类声明自己的表示、核心算法与判等方式：

| 结构 | 表示 | 核心算法 | 判等 |
|---|---|---|---|
| 多项式环 K[x] | 排序单项式表 | 引用 4.1 全部 | CANONICAL |
| 有理函数域 K(x) | 互素分子分母 | 引用 4.2 全部 | CANONICAL |
| 代数塔 K(x)(θ)，θ 的 q 次方等于 f(x) | 次数小于 q 的余式 | Capelli 守卫、Trager 范数分解、迹 Hermite、残数积分。根式与分数幂去壳后全归此层 | CANONICAL，前提是拒绝退化情形 |
| 超越塔 K(x)(τ₁,…,τₙ) | 塔上的分式 | Risch 算法全套：Hermite 推广、RT 残数、Risch 微分方程求解器、参数化对数导数判定 | 塔覆盖的片段内有标准型 |
| 级数与渐近 | 良序广义级数，也称 transseries | transseries 算术、首项比较定极限 | 片段内有标准型 |

四个边界裁定：

- 三角函数按图书馆定义展开为复指数，落进超越塔。sin 平方加 cos 平方等于一由商环算术自动成立，全程无恒等式规则参与
- 分段函数是语法容器：操作方式是把域内运算逐分支提升、条件交给判定系统合并。合并做成 Piecewise 结构即可，各分支覆盖完全性留作使用者的数学判断，重叠冲突能检测就标注
- 参数积分走主积分管线：参数当作新增超越常数，在含参系数域上原样运行，通式加使用条件出门。参数取特定值导致答案变形的情况由假设帧机制处理
- 特殊函数头如 Si、Erf、Bessel：查图书馆定义。声明为独立超越生成元的进塔，未求值形式的留在交互通道

输入项如何落到结构：

- 不含 x → 系数数域内部解决
- 是 x 的多项式 → K[x]
- 含除法 → K(x)
- 含根式且极小式合法 → 升代数塔
- 含 exp 或 log → 升超越塔
- 含特殊函数头 → 查图书馆后按上述规则分流
- 多种结构混合 → pushout 找公共宿主，例如 e 的 x 次方加根号 x 意味着同一座塔挂两层生成元

专用算法先行，失败再升级泛型。每层只处理自己该处理的问题：有理积分不会惊动 Risch，多项式 GCD 不会碰因式分解。

## 六、进阶功能与它们的算法

### 6.1 微分

导子的链式法则逐层穿透表达式。每种结构上的 D 规则已在第三节定义，微分只是 faithfully 应用。

### 6.2 不定积分

按被积式所属结构分派：

- 有理函数：在 K(x) 内完整闭环。例：∫dx/(x²+1)，残数 ±i/2 是待定常数，由结式解出
- 含根式：升代数塔。迹约化加残数。例：∫dx/√(x²+1) = ln(x+√(x²+1))
- 含 exp/log：升超越塔，运行完整 Risch。组件分工：Hermite 推广削掉重极点的有理部分；RT 残数给出对数项系数；Liouville 拆分限定答案的形状；RDE 即 Risch 微分方程 y'+fy=g 的求解器负责核心求解，它的度界理论决定整个搜索的完备性；参数化对数导数判定处理待定整数系数
- 含参数：整条管线在含参系数域上运行。例：∫e^(ax)dx 得 e^(ax)/a 附带 a 异于零的使用条件
- 初等原函数不存在时：同一套理论输出否定结论加证据链。正负两个方向都有定理背书，这正是 Risch 区别于启发式拼凑的本质优势

### 6.3 定积分

入口协议：先把积分区间和被积函数的定义域守卫做符号交运算，然后按三种情况执行：

- 区间完全落在定义域内：正常计算
- 交集可证明为空：返回无定义并说明原因。此时不给零，因为被积函数在那里根本不存在
- 部分重叠：在有定义的部分计算并附条件，或者走图书馆声明的复延拓分支按分支切区间

悄悄缩小区间再计算是被禁止的行为。

另有对称性定理独立于牛顿-莱布尼茨成立：奇函数在对称区间上积分为零，不需要原函数存在。周期函数同理有周期折叠。

### 6.4 方程与不等式

- 单变量代数方程：因式分解降次；二次以内根式闭式解；三次以上用 RootOf 表示，即以极小多项式加根的序号指称代数数，比较与运算走 Thom 编码
- 多元方程组：Gröbner 基消元
- 不等式：Sturm 符号判定与 CAD。CAD 即柱面代数分解，实闭域上多项式不等式与量词消去的完备决策程序。v2 从未实现 CAD，可复用的零件包括：投影所需的结式与子结式链、Sturm 序列、ℚ(α) 上精确赋值。需要新写的部分：McCallum 投影定理的实现包装、Thom 编码、胞腔树簿记、量词记账、解公式组装、相邻根的代数中点作样本点

### 6.5 极限与级数

transseries 承担：渐近展开、级数算术、首项比较输出极限值或符号判定。

### 6.6 求和与差分

差分演算与微分演算平行：Δ 算子之于求和等于 D 之于积分。包含 Faulhaber 幂和公式、Gosper 算法判定超几何项有无封闭和、定界求和。

### 6.7 微分方程

常系数线性 ODE 走特征方程加线性代数；一阶初等 ODE 直接消费 RDE 求解器。PDE 只覆盖声明的可判定类别。

## 七、判定与验证

这两个机制贯穿全部功能：

- 判定系统：规则触发前检查 guard 是否满足。判零统一走所在域的标准形比较，无法确定时返回 Unknown 并携带第三节定义的三种理由之一
- 验证系统：方程解回代、积分解微分判断。输出 VERIFIED / FAILED / UNVERIFIED 三值。验证器与求解器独立实现
- 逻辑层：判定原子之间用命题逻辑复合。两个 guard 同时成立是 and3，两个路径任一成立是 or3，guard 的否定是 not3。不做运行时量词推理——全称事实是图书馆引理，按模式匹配实例化为具体实例后交给域判定器。复合层只需三值命题运算，无需一阶逻辑的不可判定性
- 拒答协议表：

| 触发情形 | 边界名称 |
|---|---|
| 指数多项式求整数零点 | Skolem 问题：常系数线性递归是否存在零点，数学界尚未解决 |
| 超越常数组合判零且库里无对应引理 | Richardson 定理：此类零等价一般不可判定 |
| 超越方程的根之间比大小且库里无对应事实 | 此类比较不存在完备算法 |

发现新的已知边界就增补一行。这张表是数据，防止边界共识随换人蒸发。

## 九、验收方法论

- 差分生成器：随机生成初等函数 F，要求系统算出 integrate(dF/dx) 且结果求导回到 F。这是覆盖率的唯一来源
- 随机性质测试：生成器构造已知答案的表达式，用域判定器验证性质。当前覆盖九条：折叠保真、幂等指针、区间真值表、回代判官、多项式往返、判等完备、交叉相乘、GCD 整除
- 回代判官：声称的解回代原方程，eval_exact 精确求值必须为零。这是验证系统的原子，不需要外部真值
- 钉子库：退化形态和修过的 bug 逐个固化成测试，持续积累
- 符号反证：系统给出否定结论时，用符号方法生成候选反例逐一排除，保证否定可靠
- 文档现实锁定：文档声称存在的模块，磁盘上必须有

这六件构成完整的裁判标准。
